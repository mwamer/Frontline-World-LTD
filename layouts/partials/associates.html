{{- /* The public Associate Directory: one record per person, in page order. Each person is one file in data/associates/, and that file is the master record — the directory grid, the Expertise On Demand filters and the /people// profile all read it, so one edit reaches all three. `id` is the file name, added here so callers can link to the profile. Only records marked public are returned, so a person can be prepared before they are announced. Someone marked leadership: true heads the Our People leadership block, which has room for one name. Pass exclude_leadership and that first leadership record is left out of the listing, because the block has already printed it. Any further leadership record stays in the listing: the block cannot show it, so hiding it there too would drop the person off the site altogether. Call with: {{ partial "associates.html" (dict "page" .) }} {{ partial "associates.html" (dict "page" . "exclude_leadership" true) }} */ -}} {{- $all := slice -}} {{- range $id, $person := hugo.Data.associates -}} {{- if eq ($person.status | default "public") "public" -}} {{- $all = $all | append (merge $person (dict "id" $id)) -}} {{- end -}} {{- end -}} {{- $all = sort $all "weight" "name" -}} {{- $directory := $all -}} {{- if .exclude_leadership -}} {{- $directory = slice -}} {{- $claimed := false -}} {{- range $all -}} {{- if and .leadership (not $claimed) -}} {{- $claimed = true -}} {{- else -}} {{- $directory = $directory | append . -}} {{- end -}} {{- end -}} {{- end -}} {{- return $directory -}}
