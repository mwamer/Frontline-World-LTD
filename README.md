# Frontline World Ltd - Website

This is the official website for Frontline World Ltd, an interdisciplinary consultancy working across business, government, and academia.

## Project Structure

```
.
├── index.html                 # Home page
├── pages/                     # Content pages
│   ├── about.html            # About the organization
│   ├── approach.html         # Our approach and methodology
│   ├── services.html         # Services offered
│   ├── expertise.html        # Areas of expertise
│   ├── insights.html         # Research and publications
│   ├── people.html           # Team information
│   └── contact.html          # Contact information and form
├── assets/                    # Static assets
│   └── css/
│       └── styles.css        # Main stylesheet
└── README.md                 # This file
```

## Pages

- **Home**: Landing page with hero section and key service areas
- **About**: Organization mission and team overview
- **Our Approach**: Methodology and key principles
- **Services**: Detailed description of services offered
- **Expertise**: Specialist knowledge areas
- **Insights**: Research, articles, and publications
- **People**: Team and career information
- **Contact**: Contact information and inquiry form

## Getting Started

1. Clone or download the repository
2. Open `index.html` in a web browser
3. Navigate through the pages using the navigation menu

## Customization

To customize the website:

1. **Update content**: Edit the HTML files in the `pages/` directory
2. **Modify styling**: Update `assets/css/styles.css`
3. **Change colors**: Update color values in the CSS (currently using `#00a8e8` for primary blue and `#1a1a1a` for dark)
4. **Add images**: Create an `assets/images/` directory and add image files
5. **Update contact form**: Configure the form action to point to your email service
